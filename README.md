# Interactive Job and Internship Platform  
*For Technical Education Department, Government of Rajasthan SIH-1632*

## Project Overview

This platform is designed to connect technical education students in Rajasthan with job and internship opportunities offered by various industries, government bodies, and educational institutions. It serves as a centralized, interactive portal where students can create profiles, apply for openings, and enhance their employability, while employers and institutions can post vacancies, manage applicants, and collaborate efficiently.

---

## Features

- **Student Portal:**  
  - Profile creation with academic, skill, and project details  
  - Job and internship search with filters  
  - Resume builder and skill assessments  
  - Application tracking and notifications  

- **Employer Portal:**  
  - Company profile management  
  - Posting and managing job/internship openings  
  - Reviewing, shortlisting, and communicating with candidates  
  - Scheduling interviews and campus recruitment drives  

- **Educational Institution Portal:**  
  - Student profile verification and management  
  - Collaboration with employers for placements and internships  
  - Organizing job fairs and training programs  

- **Interactive Tools:**  
  - AI-based job matching and recommendations  
  - Real-time communication (chat/video) between students and recruiters  
  - Discussion forums for networking and career guidance  

- **Admin Dashboard:**  
  - Analytics on placements, user activity, and market trends  
  - User and content moderation  
  - Data security and verification controls  

---

## Technology Stack

- **Frontend:** React.js, Redux, Tailwind CSS (or Bootstrap)  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (or PostgreSQL)  
- **Authentication:** JWT, OAuth  
- **Hosting:** Vercel (Frontend), Render (Backend)
